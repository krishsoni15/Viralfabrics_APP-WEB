ViralFabrics PR #3 - Optimization & Bug Fixes Summary
===================================================

This document provides a summary of the improvements, bug fixes, and cleanups applied to the 'vishal-fixes-01-07-2026' branch.

1. SUMMARY OF CHANGES BY FILE
-----------------------------

A. app/(pages)/(dashboard)/hooks/useSocketLogoutListener.ts
   - FIXED: Hook cleanup logic to prevent memory/socket connection leaks in the browser.
   - Introduced a shared performCleanup() helper that is called when the last active layout instance unmounts.

B. lib/dbConnect.ts
   - FIXED: Lowered connection timeouts to 3000ms (3 seconds) to ensure database connection failures fail in 7 seconds total (safely under Vercel's 10-second serverless execution limit).
   - OPTIMIZED: Commented out the global mongoose mutation plugin. This prevents redundant SystemConfig database writes, cutting database write traffic in half (50% reduction).
   - CLEANED: Disabled background startPoolMonitoring() interval timer to eliminate serverless CPU churn.
   - **SECURITY FIX**: Added a global query middleware plugin that automatically scans and sanitizes all Mongoose `$regex` queries, protecting the entire backend globally against Regex Denial of Service (ReDoS) attacks.

C. lib/logoutAllCache.ts
   - OPTIMIZED: Lowered cache TTL from 30 seconds to 5 seconds. This ensures serverless instances stay synced with admin "Logout All" events quickly without stale data.

D. Dead Code Cleanup
   - DELETED: app/(pages)/(dashboard)/hooks/useLogoutListener.ts (Unused SSE listener).
   - DELETED: app/api/auth/logout-events/route.ts (Unused SSE endpoint).
